# Book Manager

## Sprint 1

### Objetivo

Desarrollar una aplicación de consola para gestionar libros y sus entidades relacionadas, aplicando programación orientada a objetos, persistencia mediante archivos CSV y buenas prácticas de desarrollo de software.

### Introducción y contexto

Este proyecto consiste en desarrollar un sistema de gestión de libros inspirado en el funcionamiento de una librería. La aplicación permitirá administrar la información de los libros, sus géneros, editoriales, monedas, precios, existencias y cotizaciones del dólar.

Durante el Sprint 1 se implementarán progresivamente las funcionalidades establecidas en el trabajo práctico, respetando las interfaces proporcionadas por la materia y separando las responsabilidades entre entidades, repositorios, servicios e interfaz de usuario.

La aplicación se desarrollará en Python, utilizando archivos CSV para la persistencia de los datos y una interfaz de consola para la interacción con el usuario.
